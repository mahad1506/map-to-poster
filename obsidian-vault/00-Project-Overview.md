# map-to-poster — Project Overview

- Version: 1.0.0
- Type: module

Description
A small web app to generate poster-style map images using Leaflet and MapLibre, with export presets and artistic themes.

Key files
- [index.html](index.html)
- [main.js](main.js)
- [package.json](package.json)
- [src/](src/)

Dependencies
- html2canvas
- leaflet
- maplibre-gl

Notes
- Build with `vite` (see `package.json`).
- Designed around two rendering modes: tile (Leaflet) and artistic (MapLibre GL).
