# `src/core/artistic-themes.js`

Summary
- Predefined artistic color palettes and palettes tailored for MapLibre styles.
- Keys like `cyber_noir`, `golden_era`, `mangrove_maze` are used in the UI picker.

Notes
- Artistic themes include layered color choices for water, parks, roads, text, background.
- Custom themes are prefixed with `custom_` and stored via `custom-themes.js`.
